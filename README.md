Um assistente virtual inteligente desenvolvido em **Python** e **Streamlit**, integrado à API do **Google Gemini**, projetado para auxiliar estudantes do **Ensino Médio** nas disciplinas de **Matemática** e **Língua Portuguesa**.

---

## 💡 Sobre o Projeto

Este sistema foi desenvolvido como **Projeto de Extensão Universitária** com o objetivo de democratizar o acesso ao reforço escolar por meio da Inteligência Artificial Generativa.

Diferente de um chat comum que apenas entrega o resultado final, o **Tutor de IA** utiliza engenharia de prompts dedicada para atuar de forma pedagógica e socrática:
- **Passo a passo guiado:** Incentiva o raciocínio lógico do estudante antes de revelar a resposta.
- **Explicações didáticas:** Adapta a linguagem para o nível do Ensino Médio, usando exemplos práticos.
- **Foco disciplinar:** Direciona o atendimento exclusivamente para dúvidas de Matemática (cálculos, álgebra, geometria) e Português (gramática, interpretação de texto e redação).

---

## ✨ Funcionalidades

- **Interface em Formato de Chat:** Experiência fluida, responsiva e intuitiva construída com Streamlit.
- **Memória de Contexto:** Mantém o histórico da conversa durante a sessão para acompanhar a evolução do raciocínio do aluno.
- **Engenharia de Prompts Modularizada:** Regras de negócio e instruções de sistema isoladas no back-end para garantir que a IA mantenha a postura de professor/tutor.
- **Respostas Rápidas:** Integração otimizada com o modelo **Gemini Flash** para baixa latência.

---

## 🛠️ Tecnologias Utilizadas

- **[Python](https://www.python.org/):** Linguagem base do projeto.
- **[Streamlit](https://streamlit.io/):** Framework para criação da interface web interativa.
- **[Google Generative AI (`google-generativeai`)](https://ai.google.dev/):** SDK oficial para consumo dos modelos Gemini via Google AI Studio.
- **[Python-dotenv](https://pypi.org/project/python-dotenv/):** Gerenciamento seguro de variáveis de ambiente (opcional/recomendado).

---

### Pré-requisitos
- **Python 3.10** ou superior instalado.
- Uma chave de API do Google Gemini gerada gratuitamente no [Google AI Studio](https://aistudio.google.com/).
